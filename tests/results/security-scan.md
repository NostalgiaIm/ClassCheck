# 安全性检查

执行日期：2026-09-19

## 检查范围

- 导入文件大小、文本长度和最大行数。
- HTML 显示转义。
- Excel 公式样式输入拦截与导出前缀。
- JSON 备份字段白名单和状态值校验。
- 纯本地 OCR 资源路径。
- Service Worker 只处理同源请求。
- IndexedDB 写入采用批量事务，避免导入过程中出现半成品。
- 本地数据库读取后的学生、查寝批次和明细状态归一化，以及非法路由/状态安全回退。

## 结果

静态安全检查已通过：`npm test` 已验证公式注入拦截、最大行数限制、资源路径、无外部 URL、状态值白名单和本地状态归一化；生产构建已通过。保存查寝时按批次替换明细，避免同一宿舍旧学生记录残留；Service Worker 使用版本化缓存，并在离线导航时回退到本地入口。浏览器侧仍需补做真实文件下载、目录权限回退和离线刷新验证。

## 限制

依赖漏洞审计需要访问 npm 审计服务；本项目核心功能不依赖网络，但依赖版本风险仍应在有网络条件时使用 `npm audit` 复核。
