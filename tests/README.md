# CatCheck（喵喵查寝）测试资料

[English README](../README.md) | [中文项目首页](../README.zh-CN.md)

本目录用于验证离线查寝工具的核心流程、导入识别、导出保存、备份恢复、数据整洁性和安全边界。

## 目录

- `test-cases.md`：功能与交互测试用例。
- `test-cases.csv`：可用 Excel 打开的测试用例表。
- `fixtures/`：名单文本、Markdown、CSV 和图片识别样本。
- `results/`：测试执行结果和安全性检查结果。
- `run-static-tests.mjs`：无需浏览器即可执行的解析器与静态安全检查。

## 执行

```bash
npm test
npm run build
```

浏览器交互测试需要启动开发服务器，并按 `test-cases.md` 逐项操作。

## 测试原则

- 所有名单导入都必须先预览，确认后才写入 IndexedDB。
- 导入、识别、导出、备份恢复不调用外部服务。
- 姓名、班级、备注等文本在页面显示前转义。
- 导入内容限制文件大小、文本长度和最大行数。
- 疑似 Excel 公式的输入会被拦截，导出时也会加前缀防止被表格软件执行。
- 目录写入失败时回退为浏览器下载，不阻断用户保存结果。
