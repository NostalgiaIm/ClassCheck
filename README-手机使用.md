# CatCheck（喵喵查寝）手机使用说明

[English README](README.md) | [中文项目首页](README.zh-CN.md)

## 推荐方式：安装 Android 应用

安装由项目构建出的 APK 后，点击“喵喵查寝”图标即可使用，不需要电脑服务。应用的名单、点名、OCR、历史和导出都在手机本机完成。

首次安装或升级时，Android 可能要求你确认允许来自该来源的安装包。只安装自己构建或可信来源提供的 APK。

### 第一次使用

1. 进入顶部“名单”。
2. 选择表格/文本或图片名单；名单只需要宿舍号、姓名、班级。
3. 检查导入预览，确认后再写入本机。
4. 进入“今日”，点击“开始查寝”，在弹窗内填写查寝人姓名。
5. 在“选择宿舍”页选择寝室。所有学生初始为“到”。
6. 仅把异常学生改成“未到”或“请假”，并填写显示出的原因栏。
7. 点击“保存”留在当前寝室，或“下一个寝室”保存后继续。
8. 点击“结束查寝”，选择 Markdown、PNG、JPG 或 Excel 导出本次汇报。

导出文件会保存到系统“下载/喵喵查寝”。不同手机的文件管理器显示略有差异，可在“下载”或“文件”应用中查找。

### 走读标记

进入“名单”，在对应寝室点击第三个“走读”操作，再按姓名切换标记。走读只是名单标记，不会自动把学生从点名、统计或汇报中排除。

### 备份与换机

在“名单”导出 JSON 备份；换手机后通过“恢复备份”先查看数量再确认。清除应用数据、卸载应用或清理浏览器站点数据都会删除未备份内容。

## iOS 包方式

Release 附件 `CatCheck-iOS-M3-TopNav-v1.2.3.zip` 提供 iOS SwiftPM/WKWebView 源码包，界面与 Android APK 使用同一套内置 Web 资源。它不是可直接安装的 IPA；需要用 Xcode 打开、签名后运行到模拟器或真机。

1. 解压 `CatCheck-iOS-M3-TopNav-v1.2.3.zip`，或直接使用仓库中的 `ios/CatCheck/`。
2. 安装 Xcode 15 或更新版本。
3. 用 Xcode 打开 `ios/CatCheck/Package.swift`。
4. 选择 iOS 16+ 模拟器运行；如果要装到真机、TestFlight 或 App Store，需要配置自己的 Apple Developer 团队和签名。

iOS 包使用 WKWebView 加载内置资源，名单、历史、OCR 和导出仍保存在设备本地。由于 iOS 对文件系统和导出的权限策略与 Android 不同，真机发布前应重点复测导入、导出、备份恢复和离线打开。

## 浏览器/PWA 方式

此方式适合调试或临时使用。电脑和手机在同一 Wi-Fi 时，在电脑项目目录运行：

```powershell
npm run dev -- --host 0.0.0.0 --port 5180
```

用手机打开终端显示的局域网地址，例如 `http://192.168.1.23:5180/`。请替换为电脑真实 IPv4；`localhost` 和 `127.0.0.1` 在手机上不可用。

要把网页版添加到桌面和测试完全离线，应部署至 HTTPS 静态站点，先完整打开一次，再通过浏览器“安装应用”或“添加到主屏幕”。

## 常见问题

| 问题 | 处理 |
| --- | --- |
| 图片识别有误 | 使用清晰、正向的图片；导入预览中核对姓名和宿舍号后再确认。 |
| 导出文件找不到 | 到系统“下载”或“文件”应用中查找“喵喵查寝”目录。 |
| 换设备后名单不见了 | 在旧设备导出 JSON 备份，在新设备恢复。 |
| 手机打不开电脑服务 | 确认同一 Wi-Fi、使用电脑 IPv4 和正确端口，并检查防火墙。 |
| 浏览器没有安装选项 | 使用 HTTPS 地址并让页面完整加载一次；仍可直接在浏览器中使用。 |
| iOS 包不能直接安装 | Release 中提供的是 SwiftPM/WKWebView 源码包，不是 IPA；请用 Xcode 打开 `ios/CatCheck/Package.swift` 并完成签名。 |
