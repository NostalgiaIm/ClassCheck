# CatCheck v1.2.1

## Built-in update source

- Removed the editable update-manifest address from the Android update screen.
- Moved the official HTTPS manifest URL into the Android native update manager; the web UI can only request an update check.
- Preserved HTTPS-only downloads, package/version validation, APK size and SHA-256 verification, signing-certificate verification, and Android system installation confirmation.
- Added static regression coverage to prevent a user-editable update source from returning.

## Privacy

- Update requests are made only after the user chooses “检查更新”.
- The updater does not upload the local roster, attendance records, exports, backups, or checker name.
- The update host can still receive ordinary network request metadata such as IP address and request time.
