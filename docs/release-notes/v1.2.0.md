# CatCheck v1.2.0

## In-app update delivery

- Added the self-hosted Android update screen under “名单”.
- Saves a maintainer-provided HTTPS update manifest URL only on the device.
- Validates HTTPS URLs, higher version code, package name, APK size, SHA-256, and signing certificate before the package is offered for installation.
- Uses Android's system installer confirmation; CatCheck does not silently install updates.
- Keeps WebView navigation constrained to packaged local assets even though the native updater needs network access.
- Adds `update-manifest.example.json`, a generated `updates/latest.json`, and `tools/publish-update.ps1` for future releases.

## Verification

- `npm test` passed.
- `npm run build` passed.
- Android debug APK build passed.

## Package note

`CatCheck.apk` is a debug-signed Android 10+ test package. It can update only installations signed with the same debug certificate. Before distributing a long-lived release, configure a stable release keystore and regenerate the APK, SHA-256, certificate fingerprint, and update manifest.
