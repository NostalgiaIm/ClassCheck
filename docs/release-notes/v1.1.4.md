# CatCheck v1.1.4

## Release summary

This release packages the current offline CatCheck / 喵喵查寝 Android app. The APK is provided as a GitHub Release asset; it is not committed to the source branch.

## Updated

- Added the bilingual English-first project documentation and Chinese README switch.
- Documented the offline-first architecture, Android WebView shell, test scope, contribution rules, and version history.
- Kept room-based attendance as the primary workflow: checker name, room selection, default-present status, exception reasons, save/next-room, and export.
- Kept local roster import and OCR support for room number, student name, and class; student numbers are not used.
- Kept commuter marking separate from attendance and report statistics.
- Kept local history, JSON backup/restore, spreadsheet/image/report exports, and browser download fallback.
- Added repository hygiene rules so APKs, signing files, build output, local databases, and personal data stay out of Git.

## Verification

- `npm test` passed.
- `npm run build` passed.
- Android debug APK built from the `1.1.4` source configuration.
- Device-specific download, installation, and offline checks should still be performed on the target phone.

## Package

The release asset is named `CatCheck.apk`. It is a debug build and is intended for testing and direct installation on Android 10 or newer. A production-signed package requires the maintainer's private signing key and is not included in this repository.
